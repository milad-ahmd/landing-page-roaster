## 📦 Install

**One command (installs the whole collection):**

```bash
curl -fsSL https://raw.githubusercontent.com/milad-ahmd/agent-skills/main/install.sh | bash -s -- landing-page-roaster
```

**Manually (Claude Code):**

```bash
git clone https://github.com/milad-ahmd/landing-page-roaster /tmp/landing-page-roaster
mkdir -p ~/.claude/skills && cp -r /tmp/landing-page-roaster/skills/landing-page-roaster ~/.claude/skills/
```

**Per project:** copy `skills/landing-page-roaster` into `<project>/.claude/skills/`.
**Any other agent:** paste [`SKILL.md`](skills/landing-page-roaster/SKILL.md) into your rules or system prompt.

## 💬 Usage
